Two separate problems, neither of which a builder can solve alone. 1. The catalogue reference is a monograph. Newman & Thomas-Alyea is not on disk. Whether a named monograph on disk may source a textbook-canonical case is settled (see docs/standing-decisions.yaml) — but the book still has to be on disk, and it is not. 2. The auto-resolved DOI is a different, and arguably better, source. Pabst (2014) is exactly this case's structure (S10) and, being an *analytical* solution, would give a rank-2 validation under the builder brief — an identity the model must satisfy — rather than a digitised figure. That is worth having for a T0/P1 case. Its only open-access copy is at JuSER (Forschungszentrum Jülich), record 154315, file FZJ-2014-03663.pdf. The direct file URL is recorded above and was obtained from the OpenAIRE index. juser.fz-juelich.de serves a JavaScript bot challenge (`/fast-challenge/`, 248-byte stub) to curl and to WebFetch alike, with or without a browser user-agent, cookie jar or referer; working around it would be scraping past an access control, so it was not attempted. It opens normally in a browser. OpenAlex also flags that copy as `submittedVersion`. So even once downloaded it is an author manuscript and its identity and equation numbering must be checked against the published JCP article before anything is transcribed from it.
